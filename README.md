# Guess the Secret Word
*A terminal game by Team 4DToes*  

> “Can you outsmart the Leader and uncover the secret word before your turns run out?”

---

## 🕹️ Overview  
This is a **simple, text-based Python game** where:  
- One **Leader** secretly enters a word 
- **2–4 Players** take turns asking questions or guessing 
- Each player can either:
  - Ask the Leader a **yes/no question**, or  
  - Guess with **`guess: <word>`**  
- If someone guesses correctly, they win!!  
- If not... the secret is revealed at the end!

---

## How to Run  
1. Make sure you have **Python 3** installed.  
2. Save the file as `game.py`.  
3. Open your terminal or command prompt.  
4. Run the game with:
   ```bash
   python game.py
